I put together a UK edition of the FIFA World Cup 2026 calendar using Claude — all 104 matches, with kick-off times and which channel each game is on (BBC or ITV).

How to import

Google Calendar

  1. Download the .ics file above.
  2. Go to calendar.google.com and sign in.
  3. Click the + next to Other calendars in the left sidebar.
  4. Select Import.
  5. Choose the downloaded file and click Import.

All 104 fixtures will appear as individual events, automatically converted to your local time zone.

Apple Calendar (Mac)

  1. Download the .ics file above.
  2. Double-click the file — Apple Calendar opens automatically.
  3. Choose which calendar to add the events to and click OK.

Tip: Choose your iCloud calendar so fixtures sync to your iPhone and iPad automatically.

Microsoft Outlook (Windows)

  1. Download the .ics file above.
  2. Open Outlook and go to File → Open & Export → Import/Export.
  3. Select Import an iCalendar (.ics) or vCalendar file and click Next.
  4. Browse to the downloaded file and click OK.
  5. Choose Import to add to your existing calendar, or Open as New for a separate World Cup calendar.

Outlook.com: Click the calendar icon → Import calendar in the left panel → upload the .ics file.

Windows Calendar

  1. Download the .ics file above.
  2. Double-click the file in File Explorer — Windows will prompt you to import it.
  3. Click Import to confirm.
